# OTC Clearing

Concepts are indexed in the shared [concept catalogue](../foundation.md), with annotations in [concept annotations](../concept-annotations.md). This module will hold detailed Markdown concept fiches (`LD-Cnnnn.md`) for concepts it owns.

Reuse shared concept IDs; only introduce a specialisation when its meaning, constraints or applicability justify it. Phase 2 development is authorised in the order Common, Execution, ETD Clearing, OTC Clearing; individual definitions remain Draft.
