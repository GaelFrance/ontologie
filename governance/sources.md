# Source register

Status: Background references, not universal rules or approval evidence

The initial modelling proposal and scope derive from the business sponsor's request and review discussion. The following references informed the distinction between vocabulary, ontology and context-dependent clearing workflows; their current versions must be reviewed before adopting market-specific rules.

| ID | Reference | Use and limitation |
|---|---|---|
| SRC-001 | [W3C SKOS Reference](https://www.w3.org/TR/skos-reference/) | Vocabulary organisation; does not mandate a Phase 1 implementation format |
| SRC-002 | [W3C OWL overview](https://www.w3.org/OWL) | Formal ontology representation; no OWL implementation selected |
| SRC-003 | [CME Allocation Management](https://cmegroupclientsite.atlassian.net/wiki/spaces/EPICSANDBOX/pages/457216632/Allocation%2BManagement%2BFIXML%2BAPI) | Illustrates distinct allocation, average-price and give-up workflows; not a universal clearing rule |
| SRC-004 | [LCH SwapClear Risk Management](https://www.lseg.com/en/post-trade/clearing/lch-services/swapclear/risk-management) | Background on margin; not a universal client-margin model |

The public regulatory and industry references used by the 2026-11 expert review, and which of them were checked, are listed in the [arbitration record](reviews/2026-11-expert-review/ARBITRATION.md#5-claims-verified-and-to-verify); none is yet a source-level validation.

For future adopted rules, record exact document/version, section, source date, access date, jurisdiction/service, supported claim and reviewer. These preliminary links do not constitute a source-level validation of any definition in the catalogue.
